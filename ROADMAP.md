# Roadmap

The roadmap optimizes for trustworthy data and contributor retention, not feature count. Star counts are an outcome, not a promise.

## v0.1 — trustworthy vertical slice

- [x] Beijing, Chengdu, and Lijiang sample records
- [x] Source and verification-date requirements
- [x] CLI search, city guide, rule-based plan, and freshness report
- [x] Local HTTP API
- [x] Read-only MCP server
- [x] Tests, CI, contribution guide, and issue forms
- [ ] Independent review of all six sample records by local contributors

## v0.2 — contribution flywheel

- [ ] Add a `new-city` scaffolding command
- [ ] Validate against the full JSON Schema in CI
- [ ] Add controlled vocabularies for categories, warnings, and accessibility
- [ ] Label stale records automatically
- [ ] Publish a lightweight documentation site
- [ ] Reach 10 cities through contributor pull requests

## v0.3 — reliable live integrations

- [ ] Define provider interfaces for weather and public transport
- [ ] Add caching, source timestamps, and provider health metadata
- [ ] Add a policy registry that stores links and effective dates, not legal conclusions
- [ ] Export offline Markdown travel packs

## v1.0 — stable public data contract

- [ ] Versioned schema migration policy
- [ ] 30 reviewed cities with named maintainers
- [ ] Data quality dashboard
- [ ] Stable MCP and HTTP response contracts
- [ ] Accessibility and food-allergen review guidelines

## Explicitly deferred

Live booking inventory, hotel rankings, visa eligibility decisions, and turn-by-turn navigation are deferred until the project has authoritative providers, sustainable maintenance, and clear liability boundaries.
